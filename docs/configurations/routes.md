## Routes

`MageSetu_AiBase` does not declare any custom frontend or admin routes.

- No `routes.xml` file exists in the module.
- The module does not expose controllers or direct HTTP endpoints.

## Notes

This module is intended as a backend integration layer and does not provide any UI or route by itself. Any routing requirements must be implemented by consuming modules.
